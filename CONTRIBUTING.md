# Contributing to PureLang

Thank you for your interest in PureLang!

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a feature branch: `git checkout -b feature/my-feature`
4. Make your changes
5. Commit with clear messages
6. Push and open a Pull Request

## Development Setup (Future)

Once the compiler scaffolding exists:

```bash
# Requires Rust toolchain
cargo build
cargo test
```

## Code of Conduct

Be respectful, constructive, and focused on improving the language and its tooling.

## What We Need Help With

- Language design feedback (syntax, ownership ergonomics)
- Compiler implementation (lexer, parser, type checker, codegen)
- Documentation improvements
- Example programs
- Testing and fuzzing
- Tooling (formatter, LSP, package manager)

## Pull Request Guidelines

- Keep PRs focused and reasonably sized
- Add tests when adding compiler features
- Update documentation when changing public behavior
- Ensure CI passes

We welcome contributions of all sizes — from fixing typos in the docs to major compiler features.
